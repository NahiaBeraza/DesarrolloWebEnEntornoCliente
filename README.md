# Wordle
En este trabajo crearemos una "replica" del **Wordle** para aprender a validar diferentes elementos de *Java Script*.

### ***Nahia Beraza***

## Caracteristicas principales del **Wordle**
+ Limite de intentos.
+ Pistas de colores
    1. *Verde:* La letra está en la palabra y en la posición correcta.
    2. *Naranja:* La letra está en la palabra, pero en una posición incorrecta.
    3. *Gris*: La letra no está en la palabra.
+ Palabras validas (qué existan).
+ Formato sencillo
Y muchas otras caracteristicas más.
